# School-Clock
This app will run on every smart board in the school which will notify students when class begins/ends and what class they currently have.

# Warning
This app is made with the assistance of Claude Code.

# Installation Process

## This process varies between boards, but it's more or less the same.

1 - Download the ".apk" file and copy it to a flash drive.

2 - Plug it into the Android smart board.

3 - Go to settings and select about device.

4 - Tap build number 7 times (Enable Developer mode)

5 - Android Settings -> Enable Unknown Source (or similar)

6 - Go to the folders app and navigate to the ".apk" file.

7 - Your done!
